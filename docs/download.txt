Download
========

How to install puddletag, from PyPI, from your distribution's packages or from its source code, and what each way needs, is kept in one place: the `README <https://github.com/puddletag/puddletag#how-to-install>`_ on GitHub.

Each release is on `PyPI <https://pypi.org/project/puddletag/>`_, and its source on GitHub's `releases page <https://github.com/puddletag/puddletag/releases>`_.

.. _development_builds:

Development builds
------------------

Every change merged into puddletag is published to `TestPyPI <https://test.pypi.org/project/puddletag/>`_ as a pre-release. To run the latest code from its source, follow the README's `Source Code <https://github.com/puddletag/puddletag#source-code>`_ section.
